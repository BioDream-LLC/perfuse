Getting started

Running in a minute

1. Unpack it

On Windows, unzip the file. On macOS or Linux:

tar xzf perfuse-v0.1.21-*.tar.gz

2. Start it

On Windows, double-click perfuse.exe. Elsewhere:

./perfuse serve

The first start prints the administrator's password once.

3. Open the console

Go to http://127.0.0.1:8080, sign in, and build your first channel. The manual walks through it.

To keep it running

perfuse init installs it as a service: systemd on Linux, launchd on macOS, or a Windows service.

Other ways

Containers, Go and source

# Go 1.23 or newer
go install github.com/biodream-llc/perfuse/cmd/perfuse@latest

# Container: nothing inside but the program
docker build -t perfuse . && docker run -p 8080:8080 perfuse

# From source
git clone https://github.com/biodream-llc/perfuse && cd perfuse && make build
